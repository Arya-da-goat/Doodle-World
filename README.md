# Doodle Realms 3D V1

Mobile-friendly 3D open-world RPG prototype for GitHub Pages.

### Features
- Three.js 3D world
- Third-person camera
- Mobile doodle joystick
- PC WASD/arrow controls
- Player movement
- Village and forest
- 8 enemies with chase AI
- Attack button and combat
- HP, XP, levels and gold
- Respawn

### GitHub Pages
Upload all four files to a repository. Go to **Settings → Pages → Deploy from a branch**, select your main branch and root folder.

`game.js` imports Three.js from jsDelivr, so the game needs an internet connection when loaded.

### Next version ideas
